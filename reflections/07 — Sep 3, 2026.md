# Lecture 07 — Sep 3, 2026

## Reflection Journal

> This lecture focused on making graphical applications more practical and user-friendly. I learned how large datasets can be displayed clearly, how JavaFX interfaces can be structured using FXML, and how concepts such as tree structures, serialization, and multithreading can be applied to real applications.

---

## 01 — Displaying Results Clearly

- Understand how to display a **small number of matches** when working with a large dataset.
- Avoid unnecessary scrolling by showing only the most relevant results.
- Use **indices and ellipsis (...)** to communicate gaps between results.
- I learned that good UI design is not only about showing information, but also about presenting it in a way that is easy to understand.

---

## 02 — JavaFX and FXML

- Understand the purpose of a **splash screen** in a graphical application.
- A splash screen can display useful information while the application is loading.
- Learn how **FXML** can be used to define the structure of JavaFX interfaces.
- FXML helps separate the interface design from the Java code that controls its behaviour.

---

## 03 — Tree Structures and Objects

- Understand how a file and folder system can be represented using a **tree structure**.
- Folders can contain other folders and files, creating a parent-child relationship.
- Each element can be represented as an **object** with its own properties.
- This approach makes it possible to model and edit file-system information within a graphical application.

---

## 04 — Serialization and Saving Object State

- Revise the concept of **serialization** in Java.
- Serialization allows the state of an object to be saved to disk.
- Saved objects can later be loaded so that their previous state can be restored.
- This is useful when an application needs to preserve information between different runs.

---

## 05 — Multithreading and Progress

- Understand how multiple jobs can be executed using **threads**.
- Each task can have its own progress indicator.
- A **composite progress bar** can be used to represent the progress of multiple tasks together.
- Multithreading allows several operations to run without making the application appear frozen.

---

## 06 — Graceful Thread Cancellation

- Understand the importance of stopping threads safely.
- **Graceful cancellation** allows a running task to receive a cancellation signal and finish necessary cleanup before stopping.
- This is safer than simply terminating a thread without giving it an opportunity to clean up its resources.

---

## Overall Reflection

This lecture helped me understand that a good graphical application needs more than just working functionality. The way information is displayed, how data is structured and saved, and how background tasks are handled all affect the quality of the application.

The concepts of tree structures, serialization, and multithreading showed me how graphical programs can manage larger amounts of information while still remaining organised and responsive.
