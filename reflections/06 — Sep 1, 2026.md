## 01 — Equations, Matrices and Vectors

## 02 — Circles and Distance Calculations

- Understand how a circle can be represented using its **centre and radius**.
- Revise the distance formula for finding the distance between two points.
- Understand how the distance between a point and the centre of a circle can be compared with the radius to determine whether the point lies inside the circle.
- The distance formula can be derived using the **Pythagorean theorem**:

```text
distance = √((x₂ - x₁)² + (y₂ - y₁)²)
```
- This provides a mathematical way to perform geometric collision and containment checks.

## 03 — Java Swing and Mouse Interaction

- Understand how a graphical application can be built using Java Swing.
- Explore how a canvas containing circles and directed arrows can respond to user interaction.
- Mouse listeners can detect clicks and mouse coordinates.
- Mouse dragging can be used to create directed arrows between circles.
- This connects event handling with the coordinate-based drawing concepts covered in earlier lectures.

---

## 04 — Stacks, Queues and Undo

- Understand the difference between stacks and queues.
- A stack follows LIFO (Last In, First Out).
- A queue follows FIFO (First In, First Out).
- A stack can be useful for implementing an undo feature because the most recently created object can be removed first.

---

## 05 — Breaking Down a Graphics Project

- Understand how a larger graphics project can be divided into smaller implementation tasks.
- A project involving circles, directed arrows, mouse interaction, and undo functionality requires several concepts to work together.
- Geometry can determine where objects are placed and whether interactions are valid.
- Event handling allows the user to interact with the graphical objects.
- Data structures such as stacks can manage the application's state and support features such as undo.
