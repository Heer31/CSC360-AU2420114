## 01 — Maven and JavaFX Setup

* **Maven** is used as a build automation and dependency management tool for Java projects.
* It manages external libraries and dependencies without requiring them to be downloaded and configured manually.
* Maven can be integrated with **IntelliJ** to build and run Java projects.
* A JavaFX project can be created using Maven with a structured project setup.
* This makes managing the project and its required libraries more organised.

---

## 02 — JavaFX Shape Rendering

* JavaFX provides classes for creating and displaying **2D shapes**.
* The `Rectangle` class can be used to create shapes such as squares and rectangles.
* A shape can either be filled or displayed as an outline.
* `setFill()` controls the **inside colour** of a shape.
* `setStroke()` controls the **colour of the boundary**.
* `Color.TRANSPARENT` can be used with `setFill()` to create a hollow shape.
* `setStrokeWidth()` controls the **thickness of the outline**.

---

## 03 — Shape Position and Size

* JavaFX provides properties that control where a shape appears and how large it is.
* `setLayoutX()` changes the horizontal position of a shape.
* `setLayoutY()` changes the vertical position of a shape.
* `setWidth()` controls the width of the shape.
* `setHeight()` controls the height of the shape.
* Changing these values directly affects the shape's position and appearance on the screen.

## 04 — Practical Application

* A basic **JavaFX 2D program** was created using Maven.
* The `Rectangle` class was used to create and display a square.
* The square was modified to become hollow using:

```java
rectangle.setFill(Color.TRANSPARENT);
rectangle.setStroke(Color.BLACK);
```

* The size and position of the square were changed by modifying its JavaFX properties.
* The border thickness could also be adjusted using `setStrokeWidth()`.
* This practical work helped me understand how JavaFX properties can be used to control the appearance and behaviour of graphical objects.
