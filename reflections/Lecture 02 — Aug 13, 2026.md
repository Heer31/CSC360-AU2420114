# Lecture 02 — Aug 13, 2026

## Reflection

### Maven and JavaFX Setup

* [ ] Understand the purpose of **Maven** as a build automation and dependency management tool for Java projects.
* [ ] Understand how Maven manages external dependencies instead of requiring libraries to be downloaded and configured manually.
* [ ] Understand how Maven can be used inside IntelliJ to build and run Java projects.
* [ ] Understand the basic structure of a JavaFX project created using Maven.

### JavaFX Shape Rendering

* [ ] Understand how 2D shapes such as **Rectangle** are created and displayed in JavaFX.
* [ ] Understand the difference between a filled shape and a hollow/outline-only shape.
* [ ] Understand how `setFill()` is used to define the inside colour of a shape.
* [ ] Understand how `setStroke()` is used to define the colour of a shape's boundary.
* [ ] Understand how `Color.TRANSPARENT` can be used to make a shape hollow.
* [ ] Understand how `setStrokeWidth()` controls the thickness of the shape's border.

### Shape Position and Size

* [ ] Understand how `setLayoutX()` and `setLayoutY()` are used to position a shape on the screen.
* [ ] Understand how `setWidth()` and `setHeight()` are used to control the size of a shape.
* [ ] Understand how changing these properties affects the appearance and position of a JavaFX shape.

### Practical Application

* [ ] Create a basic JavaFX 2D program using Maven.
* [ ] Create and display a square using the JavaFX `Rectangle` class.
* [ ] Modify the square to make it hollow by using `Color.TRANSPARENT` and `setStroke()`.
* [ ] Experiment with the square's size, position, and border thickness.
* [ ] Understand how JavaFX properties can be modified to control the appearance of graphical objects.
