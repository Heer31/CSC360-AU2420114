## 01 — Event-Driven Applications

- Understand the **event-driven model** used by graphical applications.
- A GUI continuously waits for actions such as mouse clicks, selections, or other user input.
- Events originate from a **source** and can propagate through the component hierarchy.
- Event listeners are responsible for detecting and responding to these events.

---

## 02 — GUI Layout and Components

- Understand the purpose of **layout managers** in GUI applications.
- Layout managers control the positioning of components and help maintain the interface when the window is resized.
- Different controls are useful for different types of input:
  - **Checkboxes** → allow multiple selections.
  - **Radio buttons** → allow one selection from a group.
  - **Sliders** → allow users to choose a value from a continuous range.
  - **Dialog boxes** → display information or require the user to respond before continuing.
- I learned that choosing the correct component can make an interface much easier to use.

---

## 03 — Exceptions in Java

- Revise the difference between **checked and unchecked exceptions**.
- Checked exceptions are handled or declared during compilation.
- Unchecked exceptions generally occur during program execution.
- Proper exception handling helps applications deal with unexpected situations more safely.

---

## 04 — Generics and Collections

- Revise **Java generics** and their role in creating type-safe code.
- Collections provide ways to store and organise groups of objects.
- Generics help specify what type of objects a collection is expected to contain.
- These concepts are useful when managing data inside larger Java applications.

---

## 05 — Preparing for Digital Image Processing

- Understand that the course is moving towards **digital image processing**.
- Image processing involves working with digital images and the data contained within them.
- The concepts learned earlier about pixels, graphics, and data structures provide a foundation for understanding image-based applications.
- This creates a connection between graphical interfaces and the processing of digital images.
