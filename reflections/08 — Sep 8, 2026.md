## Reflection

### Event-Driven Applications

- Understand the **event-driven model** used by graphical applications.
- A GUI continuously waits for user actions such as clicks, selections, or other inputs.
- An event originates from an **event source** and can propagate through the component hierarchy.
- Event listeners are responsible for responding to the events generated by the user.

---

### GUI Layout and Components

- Understand the role of **layout managers** in positioning components within a graphical interface.
- Layout managers help organise components and adjust their positions when the window is resized.
- Different GUI components are designed for different types of interaction:
  - **Checkboxes** → allow multiple independent selections.
  - **Radio buttons** → allow a single selection from a group.
  - **Sliders** → allow users to select a value from a continuous range.
  - **Dialog boxes** → display information or require the user to respond before continuing.
- Dialog boxes are useful for maintaining context and directing the user's attention to an important message or decision.

---

### Java Concepts Review

- Revise the difference between **checked and unchecked exceptions**.
- Understand that exceptions allow programs to handle unexpected situations without simply terminating.
- Revise **Java generics** and how they provide type safety when working with collections.
- Review how collections can be used to store and manage groups of objects.
- Understand how these Java concepts support the development of larger applications.

---

### Transition to Digital Image Processing

- The lecture also prepared for the transition from graphical applications to **digital image processing**.
- Understand that image processing involves working with digital images and their underlying data.
- This connects with the earlier understanding of pixels, graphics, and image representation.
- The upcoming topics will build on these concepts using image-processing libraries and techniques.
