--> 03 — Java Swing and GUI Structure

- Java Swing provides components for creating desktop graphical applications.
- The basic relationship between the main window and drawing area is:

```text
JFrame
   |
   └── JPanel
- JFrame acts as the top-level application window.
- JPanel is placed inside the JFrame and can be used as a custom drawing surface.
- The JPanel should not contain the JFrame; the frame is the outer container.

--> 04 — Turning Coordinates into Shapes

- The lecture showed how mathematical calculations can be used to construct graphical shapes.
- A rectangle can be created when two diagonal points are known.
- If the points are (x1, y1) and (x2, y2), the required values are:
  x = min(x1, x2)
  y = min(y1, y2)
  width = |x2 - x1|
  height = |y2 - y1|
- min() gives the correct top-left starting position.
- The absolute value ensures that the width and height remain positive.
- This method works regardless of which diagonal point is given first.
