## 01 — Computer Graphics Fundamentals

* **Computer Graphics** focuses on creating and generating visual content using computers.
* **Image Processing** works with existing images for purposes such as analysis, enhancement, and information extraction.
* Basic geometric primitives used in graphics include:

  * Points
  * Lines
  * Curves
  * Polygons
  * Circles
  * Other basic shapes

## 02 — Git, SSH and HTTPS

* Git repositories can be accessed using different methods, including **SSH** and **HTTPS**.
* **SSH** provides secure access and authentication through a key-based system.
* **HTTPS** allows secure communication over the web using TLS.
* An SSH key pair consists of:

  * **Public key** → can be shared.
  * **Private key** → must be kept secret.
* Understanding the difference between SSH and HTTPS is useful when working with remote Git repositories.

## 03 — Java Graphics Frameworks

* Java provides several frameworks for creating graphical applications:

  * **AWT** → uses native operating-system components.
  * **Swing** → provides flexible GUI components built on top of AWT.
  * **JavaFX** → supports modern styling, animation, graphics, and multimedia.
* These frameworks provide different approaches to creating graphical user interfaces and applications.

---

## 04 — Event Listener Model

* Java uses the **Event Listener Model** to handle user interaction.
* The main components involved are:

  * **Event Source** → the component that generates an event.
  * **Event** → the action that takes place.
  * **Event Listener** → waits for and responds to the event.
* For example, clicking a button can generate an event that is handled by a registered listener.
* This model allows graphical applications to respond to user actions.

---

## 05 — Static and Interactive Graphics

* **Static graphics** remain unchanged after they are displayed.
* **Interactive graphics** respond to user input such as:

  * Mouse movement
  * Mouse clicks
  * Keyboard input
* Event handling allows the program to detect these actions.
* Repainting can then be used to update the graphical object on the screen.

---

## 06 — Curves and Calculus

* Curves in computer graphics can be understood using concepts from **calculus**.
* **Differentiation** helps determine the slope and rate of change of a curve.
* **Integration** can be used to calculate areas under or between curves.
* These concepts are useful for defining and drawing smooth curves mathematically.

---

## 07 — Digital Images and Pixels

* A digital image can be represented as a **2D matrix of pixels**.
* Each pixel stores information such as:

  * A grayscale value
  * An RGB colour value
* The combination of these pixel values determines the final appearance of an image.
* This helped me understand how digital images are represented internally rather than just viewed as pictures.

---

## 08 — Raster and Vector Graphics

* **Raster graphics** are represented using a grid of pixels.
* Their quality depends on the image resolution.
* Enlarging a raster image too much can make it appear **blurry or pixelated**.
* **Vector graphics** use mathematical descriptions and drawing instructions instead of individual pixels.
* Because of this, vector graphics are **resolution-independent** and can be scaled without losing quality.
* The main difference is:

  * **Raster → pixel-based**
  * **Vector → mathematically defined**

---

## 09 — 2D Transformations

* 2D transformations can be used to change the position or size of graphical objects.
* **Translation** moves an object from one position to another.
* **Scaling** increases or decreases the size of an object.
* These transformations can be applied to shapes such as triangles.
* Scaling can also be used to create effects such as **zooming in and out**.

---

## 10 — Java 2D Programming

* Java can be used to create and control basic 2D graphical objects.
* A triangle can be created and displayed using coordinate points.
* Mouse movement can be connected to the position of a graphical object.
* This allows an object such as a triangle to **follow the mouse cursor**.
* This practical example helped connect programming concepts with interactive graphics.

---

## 11 — Lines and Pixels

* A **pixel** is the smallest display unit of a digital image.
* Pixels are arranged in rows and columns to form an image.
* When a line is drawn, the computer determines which pixels should be displayed to represent that line.
* This shows how seemingly smooth graphical elements are ultimately displayed using individual pixels.

---

## 12 — Windows vs Linux

* Windows and Linux can differ in how graphics and displays are handled.
* Differences can include:

  * Font rendering
  * Display behaviour
  * Hardware and graphics driver compatibility
* Graphics cards and other hardware require appropriate drivers so that the operating system and applications can communicate with them correctly.
