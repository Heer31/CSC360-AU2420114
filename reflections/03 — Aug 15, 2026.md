## 01 — Understanding the 2D Coordinate System

* The **pixel** is the basic unit used to represent position and size in 2D computer graphics.
* A canvas has a specific **width (W)** and **height (H)**.
* The centre of the canvas can be calculated using:

```text
cx = W / 2
cy = H / 2
```

* Unlike the usual mathematical coordinate system, computer screen coordinates generally begin at the **top-left corner**.
* The X-coordinate increases towards the **right**.
* The Y-coordinate increases **downwards**.

---

## 02 — Drawing a Centred Square

* A square can be positioned around the centre of a canvas using its centre point and side length.
* If the side length is `L`, then half of the side length is `L / 2`.
* The four corners can be calculated as:

```text
Top-Left     → (cx - L/2, cy - L/2)
Top-Right    → (cx + L/2, cy - L/2)
Bottom-Left  → (cx - L/2, cy + L/2)
Bottom-Right → (cx + L/2, cy + L/2)
```

* These calculations make sure that the square is positioned equally around the centre of the canvas.
* This also helped me understand how mathematical formulas can be translated directly into drawing instructions.

## 03 — Maven Project Structure

* The lecture also introduced the standard structure of a **Maven Java project**.
* Important parts of the project include:

  * `pom.xml` → contains project configuration and dependencies.
  * `src/main/java` → contains the main Java source files.
  * `src/main/resources` → contains resources used by the application.
* Understanding this structure makes it easier to locate files and understand how a Java project is organised.

---

## 04 — Java Swing and JFrame

* **Java Swing** provides components for building desktop graphical applications.
* `JFrame` acts as the **top-level window** of a Swing application.
* It provides the main container in which other GUI components can be placed.
* This helped me understand how the application window and the drawing area are structured.

---

## 05 — Static and Instance Fields

* The lecture also reinforced the difference between **static** and **instance** fields.
* A **static field** belongs to the class itself and is shared by all objects created from that class.
* An **instance field** belongs to an individual object, so each object can have its own value.
* Understanding this distinction is important when deciding whether information should be shared across objects or stored separately for each object.
