# Java GUI Frameworks

## Overview

Java provides several frameworks for creating graphical user interfaces (GUIs) and graphical applications.

The main frameworks discussed are:

* AWT
* Swing
* JavaFX

---

## 1. AWT — Abstract Window Toolkit

AWT is the original Java GUI framework.

### Key points

* AWT is part of the standard Java platform.
* It uses **native operating-system components**.
* Its components are closely connected to the underlying operating system.
* It provides basic GUI components such as windows, buttons, labels, and text fields.

### Important idea

AWT uses native components, so the appearance and behaviour of some components can depend on the operating system.

---

## 2. Swing

Swing is a GUI toolkit built on top of AWT.

### Key points

* Provides more advanced and flexible GUI components than AWT.
* Contains components such as buttons, labels, tables, menus, and panels.
* It is part of the **Java Foundation Classes (JFC)**.
* Swing components are generally more consistent across different operating systems.

### AWT vs Swing

```text
AWT
 ↓
Basic GUI components
 ↓
Uses native OS components

Swing
 ↓
Built on AWT
 ↓
More advanced and flexible components
```

---

## 3. JavaFX

JavaFX is a framework for creating modern and rich GUI applications.

### Features

* CSS styling
* Animations
* Graphics
* Multimedia
* Modern user-interface components

JavaFX is generally distributed separately from the JDK in modern Java versions, so it may need to be added as an external dependency/module.

# Event Listener Model

The **Event Listener Model** is used in Java GUI programming to handle user interactions.

It allows a program to detect an event and perform an appropriate action.

## Main Components

### 1. Event Source

The component that generates the event.

Example:

```text
Button
```

A button can generate an event when the user clicks it.

### 2. Event

An action performed by the user or generated by the system.

Examples:

* Button click
* Mouse movement
* Keyboard press

### 3. Event Firing

The event source generates or fires the event when the corresponding action occurs.

### 4. Event Listener

The listener receives the event and performs the required action.

---

## Example: Button Click

Consider a button in a Java GUI.

```text
User clicks button
       ↓
Button = Event Source
       ↓
Click Event is fired
       ↓
Registered Event Listener receives it
       ↓
Required action is performed
```

The listener therefore allows the program to respond to user interaction.

# Static vs Interactive Graphics

## Static Graphics

Static graphics are drawn and remain unchanged unless they are manually redrawn.

Example:

```text
A simple image displayed on the screen
```

The image does not respond to user actions.

## Interactive Graphics

Interactive graphics respond to user actions.

Examples of user actions include:

* Mouse movement
* Mouse clicks
* Keyboard input

When an interaction occurs:

```text
User Action
    ↓
Event detected
    ↓
Event handled
    ↓
Graphics updated
    ↓
Screen repainted
```

## Example

A triangle that follows the mouse cursor is an interactive graphical object because its position changes according to user input.

# Java 2D Programming

Java can be used to create and manipulate 2D graphical objects.

A basic Java 2D program involves:

* Creating a Java class
* Creating the main program
* Creating a graphical component/window
* Drawing graphical objects
* Handling user input
* Repainting the graphics when required

## Triangle Project

A basic practical exercise was to:

1. Create a triangle.
2. Display the triangle using Java 2D.
3. Detect mouse movement.
4. Change the triangle's position according to the mouse cursor.
5. Redraw the triangle at its new position.

This demonstrates the connection between:

```text
Java 2D
   +
Event Handling
   +
Mouse Input
   +
Repainting
   =
Interactive Graphics
```

# Geometric Transformations

Geometric transformations change the position, size, or appearance of graphical objects.

Two transformations discussed were:

## Translation

Translation moves an object from one position to another.

For example:

```text
Original position
      ↓
    Triangle
      ↓
New position
```

The size and shape of the triangle remain the same; only its position changes.

## Scaling

Scaling changes the size of an object.

It can be used to create:

* Zoom in
* Zoom out

For example:

```text
Small triangle
      ↓
    Scaling
      ↓
Large triangle
```
